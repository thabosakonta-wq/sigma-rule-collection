# Sigma Rule Collection

A cybersecurity detection engineering project demonstrating Sigma rule development and MITRE ATT&CK mapping.

## Overview

This project contains Sigma detection rules designed to identify suspicious security events and map them to MITRE ATT&CK techniques.

## Features

### Brute Force Detection
Detects repeated failed login attempts.

### User Creation Detection
Detects creation of new accounts.

### MITRE ATT&CK Mapping
Maps detections to ATT&CK techniques.
